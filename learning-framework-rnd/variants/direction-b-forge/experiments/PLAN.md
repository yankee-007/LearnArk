# Forge 8 轮实验计划

版本：0.1.0（plan-v1，2026-11-04）｜方向：`direction-b-forge`
依据：`shared/requirements.md`、`shared/acceptance.md`、`shared/spec-core.md`、`orchestration/briefs/direction-b.md`、`research-plan.md` 第 6 节。

每轮必须走完整循环：**一个可检验假设 → 实现/场景变更 → 真实独立体验者执行 → 反馈分诊 → 修复 → 另一个独立 Agent 复测 → 落盘证据**。只跑测试或只改文案不算一轮。
证据目录：`experiments/<round>/`（体验报告、阻塞表、修前修后对比、复测记录）。时间一律标明真实时间或 `LEARNARK_NOW` 模拟时间。

## 收敛规则

- 任一轮出现**阻塞缺陷**（无法开始/继续、丢数据、误记完成）时，本轮不收敛，当期修复后由未参与修复的体验者复测。
- 同一假设连续两轮未得到支持，写"假设未支持"结论并改设计，不得改预期或放宽阈值。
- 收敛 ≠ 通过：方向的最终结论由独立验收给出，本表只决定"这一轮是否可以做下一轮"。

## 每轮必交证据清单

1. `experiments/<round>/experience-<scenario>-<persona>.md`（按 `shared/scenarios/personas.md` 模板，含命令、实际输出、负担计数）。
2. 阻塞/重要缺陷表：来源、影响、责任人、修复版本、复测证据、状态。
3. 修前修后对照：同一命令在同一模拟状态下的输出差异（贴关键行，不贴整屏）。
4. 复测记录：由另一个独立 Agent 执行，附复测命令与日期。
5. 本轮假设结论：支持 / 未支持 / 无法判定（写明为什么），禁止用"基本可用"代替。

## 明确不做

- 不为通过而降低 rubric 阈值、放宽阈值、删除失败用例。
- 不用 mock 输出冒充真实导师体验；`LEARNARK_LLM=mock` 的运行必须在报告中标注"离线脚本导师"。
- 不把模拟时间说成真实长期学习；不把本地干净克隆说成真实跨设备验证。
- 不引入后台服务、账号、云端、移动端。
